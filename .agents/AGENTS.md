# 유튜브 인텔리전스 개발 및 튜닝 표준 지침 (Customization Rules)

본 워크스페이스는 유튜브 트렌드를 연구하고 실전 콘텐츠 기획 및 재생산을 목적으로 하는 크리에이터(생산자) 전용 분석 플랫폼입니다. 차후 유지보수, 기능 추가 및 수정 시 에이전트는 본 문서에 정의된 설계 규칙과 튜닝 지표를 항시 준수해야 합니다.

---

## 1. 크리에이터 타겟형 바이럴 랭킹 (Virality Score) 지침
대기업 채널 독식을 완화하고, 중소 기획의 알고리즘 떡상 사례를 발견할 수 있도록 아래 지표와 가중치를 엄격하게 유지합니다.

*   **가중치 배분 (`ranking/engine.py`내 `calculate_virality_score`)**:
    *   **구독자 대비 조회 폭발력 (`w_sub_ratio`)**: **0.35** (가장 높음. 하꼬 채널의 아이디어 대박 사례 플래깅 목적)
    *   **댓글 반응 밀도 (`w_comment`)**: **0.20** (시청자 화제성 분석)
    *   **조회 상승 속도 (`w_velocity`)**: **0.25** (대형 채널 보정용 하향 조정)
    *   **좋아요 비율 (`w_like`)**: **0.20**
*   **랭킹 주기별 시간 감쇠(Time Decay) 중력 계수**:
    *   **일간 (Daily)**: **1.2** (빠른 순환)
    *   **주간 (Weekly)**: **0.7** (꾸준한 트렌드 발굴용 완화)
    *   **월간 (Monthly)**: **0.4** (롱런하는 명작 분석용 최소화)

---

## 2. 한·일 미출시 해외 "숨은 보석 (Hidden Gems)" 탐지 룰
국내용 기획으로 즉시 재생산 및 모방이 가능한 완전 순수 해외 트렌드를 발굴하기 위한 필터 지침입니다.

*   **한·일 원천 차단**: 
    *   `VideoRank` 테이블 기준, 한국(`KR`)과 일본(`JP`)의 트렌드 랭킹 이력이 전혀 존재하지 않는 비디오 ID만 노출합니다.
    *   국가 선택기 UI(`CountrySelector.tsx`)에서 한국/일본 탭은 완전히 차단(`excludeCodes={["KR", "JP"]}`)하고 기본값은 미국(`US`)으로 로드합니다.
*   **텍스트 언어 검열**:
    *   비디오 제목과 설명에서 한글(`[\uac00-\ud7a3\u3131-\u318e]`) 또는 일본어(`[\u3040-\u309f\u30a0-\u30ff]`)가 단 한 글자라도 매칭될 시 국내 유입 및 한국 유저 개입으로 간주하여 제외합니다.
*   **정렬 및 노출 방식**:
    *   누적 조회수가 아닌 최신 트렌드 흥행 강도인 **`virality_score.desc()`** 내림차순 정렬을 고정하여, 해외에서 방금 급상승하기 시작한 가장 트렌디한 영상이 최상단에 먼저 뜹니다.

## 3. 다국어 쇼츠(Shorts) 수집 룰 (`crawler/collector.py`)
YouTube API Quota를 절약하면서도 모든 국가에서 하루 최소 수십 개 이상의 고품질 쇼츠 데이터를 풍성하게 모으기 위한 수집 공식입니다.

*   **ISO 639-1 언어 매핑**:
    *   API 쿼리 날릴 시 `relevanceLanguage`는 국가 코드가 아닌 `ko`, `en`, `ja`, `hi` 등 언어 규격 코드(`LANG_MAP`)를 변환해 매핑해야 수집 에러가 나지 않습니다.
*   **다중 해시태그 교차 수집**:
    *   국가별 숏츠 특성에 맞춰 검색 키워드 목록(한국의 경우 `#쇼츠`, `#숏폼`, 일본의 경우 `#ショート`, `#ショート動画` 등)을 복수 설정하여 순차 조회한 뒤, `set()`을 이용해 비디오 ID를 중복 제거(Deduplication)하여 대량 수집합니다.

## 4. 프론트엔드 호버 미리보기 팝업 (Iframe Mini Player) 규격
새 창 이동 전에 마우스 오버만으로 영상을 바로 벤치마킹 분석할 수 있도록 하는 플레이어 스펙입니다.

*   **재생 조건**: 무음(`mute=1`), 자동재생(`autoplay=1`), 영상 무한 루프(`loop=1&playlist={video_id}`), 컨트롤 숨김(`controls=0`), 마우스 클릭 간섭 차단(`pointer-events: none`).
*   **3배 대형 팝업 사이즈 지침**:
    *   **일반 롱폼 영상**: 가로 **`560px`** x 세로 **`315px`** (유튜브 표준 비율)
    *   **쇼츠 영상**: 가로 **`350px`** x 세로 **`622px`** (세로형 스마트폰 비율 보정)
*   **동작 방식**: 썸네일 영역 마우스 무브 트래킹(`mousePos`)으로 팝업이 따라다니게 처리하며, 마우스 클릭 시 새 창에서 전체 원본 화면으로 이행합니다.
